One line, 120 characters: the job you bet your life on nearly breaks you, and the silly thing you do on Sundays is what saves you instead — a reversal only an older self who lived it could write.

> The job you think will save you will nearly break you — and the silly thing you do on Sundays is what saves you instead.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`. The program scores five candidate lines against the judge's own criteria (actually told to a younger self first, then only-this-older-self-could-say-it, then one breath, then a turn, then a sting), picks the best deterministically, checks the gate itself first (1–200 characters, not only whitespace, a single line), then reads the file back to confirm what landed.
